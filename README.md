# QueryDesk — AI-Powered Document Assistant

QueryDesk is a Streamlit document assistant built with Google Gemini, LangChain, FAISS and MCP. It supports semantic RAG question answering, document summaries, exact PDF page retrieval, text search, spreadsheet previews, Pandas calculations and cross-document comparisons.

## Features

- **Formats:** PDF, DOCX, TXT, CSV, XLSX and XLS.
- **RAG:** Gemini embeddings + FAISS similarity retrieval, metadata-aware chunks and grounded answer generation.
- **MCP:** Gemini discovers and invokes format-aware document tools through an MCP client.
- **Tabular intelligence:** Pandas performs filtering, aggregation, descriptive statistics and group-by calculations.
- **Persistent library:** uploaded files and the FAISS index remain on disk between app restarts.
- **Sources:** PDF page, spreadsheet sheet and row-range metadata are retained in indexed chunks.

## Architecture

```text
Streamlit UI (agent.py)
       |
       +-- Gemini (google-genai)
       |
       +-- RAG-first retrieval (create_vector.py)
       |       +-- format-aware loaders
       |       +-- RecursiveCharacterTextSplitter
       |       +-- Gemini embeddings
       |       +-- persistent FAISS
       |
       +-- MCP client (stdio)
               |
               +-- server.py
                     +-- search_documents

                     +-- search_text_document
                     +-- read_spreadsheet
                     +-- analyze_spreadsheet
                     +-- list_documents
                     +-- compare_documents
                     +-- get_document_summary
```

## Windows installation

Use **64-bit Python 3.12.x** for this packaged version. Python 3.13 is not the target runtime for this project. A Windows setup script is included.

### 1. Extract and enter the project

```powershell
cd QueryDesk
```

### 2. Install dependencies

Run `setup_windows.bat` by double-clicking it, or use PowerShell:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Configure Gemini

Copy `.env.example` to `.env` and add your Google AI Studio API key:

```powershell
Copy-Item .env.example .env
notepad .env
```

Set `GOOGLE_API_KEY`. Do not commit `.env` to GitHub.

### 4. Launch QueryDesk

```powershell
streamlit run agent.py
```

Open the local URL printed by Streamlit (normally `http://localhost:8501`).

## Using QueryDesk

1. Upload one or more supported files in the sidebar.
2. Select **Ingest uploaded documents**. QueryDesk extracts content, chunks it, embeds it and persists the FAISS index.
3. Ask questions in the chat.
4. QueryDesk first retrieves semantically relevant chunks, then Gemini may call MCP tools for exact pages, text searches, spreadsheet operations, listing or comparison.
5. To add or update files, upload them and ingest again. Unchanged files are skipped.

## MCP tools

| Tool | Purpose |
|---|---|
| `search_documents` | Semantic retrieval from indexed chunks |
| `get_pdf_pages` | Exact one-based PDF page retrieval |
| `search_text_document` | Search DOCX/TXT paragraphs or lines |
| `read_spreadsheet` | Read CSV or a selected Excel sheet |
| `analyze_spreadsheet` | Pandas describe, filter, aggregate and group-by |
| `list_documents` | List indexed files |
| `compare_documents` | Retrieve evidence from multiple documents |
| `get_document_summary` | Retrieve document/section evidence for Gemini summarisation |

## MCP server behaviour

You do **not** need to start `server.py` manually. `agent.py` launches it automatically as a local stdio subprocess whenever a chat request needs MCP tools. Run only `streamlit run agent.py`. Starting `python server.py` manually is for diagnostics and will wait for an MCP client.

## Run ingestion from the command line

Place files in `assets/uploaded_documents`, then run:

```powershell
python create_vector.py
```

## Important notes

- FAISS indexes and uploaded documents are local application data and are excluded from Git by default. Keep backups if the documents matter.
- The index loader enables pickle deserialization because QueryDesk loads its own locally generated FAISS index. Never load a FAISS folder received from an untrusted party.
- Spreadsheet analysis is performed using controlled Pandas operations. The application does not execute arbitrary Python generated by the model.
- Document text is untrusted input. The agent prompt instructs Gemini to treat it as evidence, not as instructions.
- Scanned/image-only PDFs may require OCR; this version extracts selectable PDF text.
- Large documents and spreadsheets may take time and incur Gemini embedding usage during ingestion.
